# Better-Auth 外部サービス調査レポート

## 概要

Better-Auth の各認証機能に必要な外部サービスを調査し、モダンでコスト効率の良いサービスを提案します。

---

## 1. 外部サービスが必要な機能一覧

### メール送信が必要な機能
| 機能 | プラグイン | 用途 |
|------|-----------|------|
| Magic Link認証 | `magicLink` | パスワードレスログインリンク送信 |
| Email OTP | `emailOTP` | メールでOTPコード送信 |
| メール認証 | コア機能 | アカウント確認メール |
| パスワードリセット | コア機能 | リセットトークン送信 |
| 組織招待 | `organization` | 招待メール送信 |

### SMS/電話が必要な機能
| 機能 | プラグイン | 用途 |
|------|-----------|------|
| 電話番号OTP | `phoneNumber` | SMSでOTPコード送信 |

### CAPTCHAが必要な機能
| 機能 | プラグイン | 用途 |
|------|-----------|------|
| Bot対策 | `captcha` | 認証フォーム保護 |

### OAuthプロバイダーが必要な機能
| 機能 | 対応サービス |
|------|-------------|
| ソーシャルログイン | Google, GitHub, Discord, Apple, Microsoft, LINE等 |
| Enterprise SSO | OIDC, SAML 2.0対応IdP |

### 決済が必要な機能
| 機能 | プラグイン | 用途 |
|------|-----------|------|
| サブスクリプション | `stripe`, `polar`等 | 有料プラン管理 |

## 2. メール送信サービス比較

### 推奨順位

#### 1位: Resend (開発〜小規模向け)
```
無料枠: 3,000通/月
料金: $20/月 (50,000通)
特徴: 最もモダンなAPI、Better-Auth統合確認済み
```
- 開発者体験が最高（1分で最初のメール送信可能）
- シンプルなAPI設計
- スタートアップのMVPに最適

#### 2位: Postmark (本番環境向け)
```
無料枠: 100通/月
料金: $15/月 (10,000通)
特徴: 認証メール到達率98.7%で業界最高
```
- トランザクションメール専門
- 認証メールの到達率が最も重要な場合に選択
- テンプレートエンジン内蔵

#### 3位: Mailgun (バランス型)
```
無料枠: 3,000通/月（100通/日）
料金: $15/月 (10,000通)
特徴: 99.99% SLA、クレジットカード不要
```
- 安定性と無料枠のバランスが良い
- Webhook サポートが充実

#### 4位: AWS SES (大規模向け)
```
無料枠: 3,000通/月（12ヶ月）
料金: $0.10/1,000通
特徴: 大規模になるほど最安
```
- セットアップが複雑
- AWS環境に既にいる場合は検討価値あり

### 推奨構成
```
開発環境: Resend (無料枠で十分)
本番環境: Postmark ($15/月で高到達率を確保)
```

## 3. SMS/OTPサービス比較

### 推奨順位

#### 1位: Plivo (コスト最優先)
```
SMS料金: $0.007/通 (米国)
OTP認証: 無料（SMS料金のみ）
日本向け: $0.06-0.07/通
```
- **OTP検証サービスが無料**（最大の差別化ポイント）
- SMS送信料金のみで運用可能
- Better-Auth統合対応

#### 2位: Twilio (信頼性最優先)
```
SMS料金: $0.0083/通 (米国)
Verify API: $0.05/認証
日本向け: $0.0795/通
```
- 業界標準の信頼性とドキュメント
- Verify APIで自動OTP管理
- コストは高めだが安定性重視なら選択

#### 3位: AWS SNS (AWS統合)
```
SMS料金: $0.0025-0.0075/通
OTP認証: $0.045/認証
```
- AWS環境との親和性
- 低コストだがセットアップ複雑

### 日本国内向け特記事項
```
国際サービス経由: ¥8-12/通
国内キャリア直接契約: ¥5-10/通（大量利用時）
```
- 低〜中量: Plivo/Twilio で十分
- 大量 (1,000通/日以上): KDDI/SoftBank直接契約を検討

### 推奨構成
```
コスト重視: Plivo（OTP無料 + 低SMS料金）
信頼性重視: Twilio（業界標準）
```

## 4. CAPTCHAサービス比較

### 推奨順位

#### 1位: Cloudflare Turnstile (総合最強)
```
無料枠: 1,000,000リクエスト/月
料金: Enterprise のみ ($2,000+/月)
プライバシー: 最高（データ収集最小限）
UX: 完全invisible（ユーザー操作不要）
```
- **圧倒的な無料枠**（100万リクエスト/月）
- ユーザー体験最高（見えないCAPTCHA）
- Better-Auth公式サポート
- スタートアップに最適

#### 2位: hCaptcha (プライバシー重視)
```
無料枠: 100,000リクエスト/月
料金: $139/月 (Pro)
プライバシー: 非常に高い
UX: 画像パズル形式
```
- GDPR準拠
- Turnstileより操作が必要

#### 3位: Google reCAPTCHA v3 (非推奨)
```
無料枠: 10,000リクエスト/月（2025年に大幅削減）
料金: $8/月 (100,000リクエスト)
プライバシー: 低い（データ収集多い）
```
- 無料枠が大幅削減された
- Google Cloud移行が必要（2025年末まで）
- プライバシー懸念あり

### 推奨構成
```
スタートアップ: Cloudflare Turnstile（無料で100万リクエスト）
EU向け/プライバシー重視: hCaptcha
```

## 6. 決済サービス比較

### 推奨順位

#### 1位: Stripe (日本SaaSの標準)
```
月額固定: なし
手数料: 3.6% + ¥40/取引（日本）
特徴: Better-Auth公式プラグイン、日本法人あり
```
- 日本でのサポート体制が充実
- サブスクリプション管理機能完備
- 組織単位の課金対応
- 最も成熟したプラグイン

#### 2位: Dodo Payments (グローバル展開向け)
```
月額固定: なし
特徴: 150カ国対応、税務処理自動化
```
- Merchant of Record モデル
- 税金・コンプライアンスを自動処理
- 海外展開を見据える場合に検討

### 推奨構成
```
日本国内SaaS: Stripe（一択）
グローバル展開: Stripe or Dodo Payments
```

## 8. コスト試算例

### 月間アクティブユーザー 1,000人の場合
```
メール送信 (認証+リセット): ~2,000通/月 → 無料 (Resend)
SMS OTP: ~500通/月 → ~$35 (Plivo @ $0.07/通)
CAPTCHA: ~10,000req/月 → 無料 (Turnstile)
決済: $5,000売上 → ~$180手数料 (Stripe 3.6%)

合計: 約 $215/月（ほぼ決済手数料）
```

### 月間アクティブユーザー 10,000人の場合
```
メール送信: ~20,000通/月 → $20 (Resend Pro)
SMS OTP: ~5,000通/月 → ~$350 (Plivo)
CAPTCHA: ~100,000req/月 → 無料 (Turnstile)
決済: $50,000売上 → ~$1,800手数料 (Stripe)

合計: 約 $2,170/月
```

## 9. 実装優先順位

1. **Phase 1**: メール認証 (Resend) - 必須機能
2. **Phase 2**: OAuth (Google + LINE) - UX向上
3. **Phase 3**: CAPTCHA (Turnstile) - セキュリティ強化
4. **Phase 4**: 決済 (Stripe) - 収益化時
5. **Phase 5**: SMS OTP (Plivo) - 追加セキュリティ（必要に応じて）
